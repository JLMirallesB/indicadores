# Indicadores (Dato vs Indicador)

App web estática para GitHub Pages con materiales teóricos e interacciones breves sobre el uso de indicadores en planes de mejora educativa.

## Qué encontrarás

- Lectura guiada por bloques con mini interacción.
- Casos con interpretaciones opuestas del mismo indicador.
- Interfaz bilingüe: Castellano y Valencià.
- Proyecto 100% frontend (`HTML + CSS + JavaScript`), sin backend.

## Ver en local

```bash
cd /Users/miralles/Documents/GitHub/indicadores
python3 -m http.server 8000
```

Después abre: `http://localhost:8000`
